# StudyHub Mobile V2 Native Android

A native Android Jetpack Compose project for StudyHub.

## Features
- Login / Signup UI
- Home dashboard
- Planner
- Tasks
- Subjects
- Profile
- More menu for Notes, Quiz, Timer, Achievements, Analytics, Timetable and Settings
- Native Android Material 3 UI
- Bottom navigation
- No Streamlit or browser wrapper

## Build
Open this folder in Android Studio and let Gradle sync.
Then use:
Build > Build Bundle(s) / APK(s) > Build APK(s)

Application ID: com.studyhub.mobile
Version: 2.0.0
